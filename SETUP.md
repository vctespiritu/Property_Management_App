Post-deployment setup

1. Assign the CocoNest app to the System Administrator profile.
2. For the Administrator profile, set to Default On the Custom tabs: lease, property and tenant.
3. Assign the CocoNest_Admin_User_Access permission set to the system admin
4. For the System Administrator profile, enable the Account record types:
    1. in the System Administrator profile setup page, go down to Record Type Settings
    2. Click Edit under Account
    3. Select record types: Contractor, HOA, Property Owner, Vendor
    4. Choose default record type as Property Owner
